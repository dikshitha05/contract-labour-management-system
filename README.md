# Contract Labour Management System (CLMS)

## Project Overview
The Contract Labour Management System (CLMS) is a web-based application developed for Bharat Heavy Electricals Limited (BHEL) to manage contract employees and their biometric attendance records efficiently.

## Features
- User Authentication
- Contract Employee Management
- Add / Edit Contract Details
- Biometric Attendance Tracking
- Attendance Status Monitoring
- Employee Information Management
- Dashboard Interface

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript
- Axios

### Backend
- Spring Boot
- Java
- REST APIs

### Database
- Oracle Database
